# 运行环境

> 本文件由 `README.md` 的「运行环境」一节移入（README 只留概览与索引）。
> 文中出现的绝对路径为本机实测示例，实际使用时按各自环境替换。

- **TeX**：本地 TeX Live 2025（`xelatex` + `latexmk`，`svg` 宏包经 **Inkscape** 转换，
  故编译开启 `-shell-escape`）。
- **Inkscape / flock**：`svg` 宏包经 **Inkscape** 转 PDF；并行编译时 `tools/bin/inkscape`
  用 `flock`（util-linux）串行化 Inkscape 调用，避免并发 `Gio::DBus::Error` 崩溃。
  无 Inkscape 无法编译含 SVG 的卷；无 `flock` 时该包装退化为直接调用，需自行串行编译。
- **中文字体（自动回退）**：`gaokaozhenti.cls` 基于 `ctexbook`，并根据字体是否安装
  自动选择——优先 Windows 字体（SimSun / SimHei / KaiTi / Microsoft YaHei / FangSong），
  未安装则回退 TeX Live 自带的 Fandol（FandolSong / FandolHei / FandolFang）。
  因此**在有/无 Windows 字体的系统（Linux、CI）均可直接编译**，无需改类文件。
- **poppler**：`pdftotext`（旁证）、`pdfimages -all`（无损提图）、`pdftoppm -r 600`
  （纯矢量页渲染）。
- **splitpicture**（外部，多子图裁剪）：需在 `PATH`，或用环境变量
  `SPLITPICTURE=/path/to/splitpicture` 指定；源码见其仓库
  （<https://gitee.com/ylxdxx/splitpicture>），常用 `detect --panels`、
  `split --rects-file`、`-d` 等（`tools/recrop_figures.py`、`tools/match_figures.py` 调用）。
- **OCR**：OvisOCR3（沿用 Anaconda `ovis_ocr`，模型 `/home/shui/AI/ATH-MaaS/OvisOCR3`，
  可用 `OVIS_MODEL` 覆盖）为底本；PaddleOCR-VL（Anaconda `BaiduPaddle`，
  服务默认 `127.0.0.1:8203`）为验证；统一入口 `python3 -m tools.ocr_pipeline`，
  详见 `材料处理与OCR规范.md` 与 `OCR识别转换流程说明.md`。
- **OCR Python 依赖**：OvisOCR3 需 `vllm` / `pymupdf` / `Pillow`（`ovis_ocr` 环境已具备）；
  Paddle 客户端需 `requests`；分块需 `qpdf`（缺失时回退 PyMuPDF）。
- **Python**：`tools/` 脚本依赖 Python 3；`json_to_tex.py` / `html2latex.py` 需
  **beautifulsoup4**（HTML/公式解析）；图片匹配/裁剪自检需 **Pillow**（`PIL`）。
