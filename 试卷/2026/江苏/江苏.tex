压缩空气储存能量的某个过程中，一定质量的空气从状态 A 压缩至温度相同的状态 B，此过程中外界对空气做功为 $W$。已知状态 A 的压强为 $p_{0}$、体积为 $V_{0}$，状态 B 的体积为 $V$，空气可视为理想气体。求：
\begin{enumerate}
	\item
	该过程气体放出的热量 $Q$；
	\item
	状态 B 的压强 $p$。
\end{enumerate}
%% answer:
\jdanswer{
\begin{enumerate}
	\item
	$W$

	\item
	$p = \frac{V_{0}}{V}p_{0}$

\end{enumerate}
}
%% memo:
\memoanswer{
（1）理想气体经历从 A 状态到 B 状态等温变化，气体的内能不变，由热力学第一定律有 $\Delta U = Q + W = 0$。

解得 $Q = -W$。

负号表示过程中气体放出热量 $W$。

（2）理想气体经历从 A 状态到 B 状态等温变化，由玻意耳定律有 $p_{0}V_{0} = pV$。

解得 $p = \frac{V_{0}}{V}p_{0}$。
}

\begin{enumerate}
	\item
	向心加速度的大小 $a_{n}$；
	\item

\begin{enumerate}
	\item
	$5\ \Umsq$

	\item
	$1000\sqrt{101}\ \UN$

\end{enumerate}
}
%% memo:
\memoanswer{
（1）根据题意，由向心加速度公式可得
\[
a_{n} = \frac{v^{2}}{R} = \frac{10^{2}}{20}\ \Umsq = 5\ \Umsq.
\]

（2）汽车在最高点时，水平方向上有
\[
F_{x} = F_{\text{牵}} - f = 1\times10^{3}\ \UN,

\[
F_{y} = ma_{n} = 1\times10^{4}\ \UN,

\[
F_{\text{合}} = \sqrt{F_{x}^{2} + F_{y}^{2}} = 1000\sqrt{101}\ \UN.

%% method: 无

%% body:
巡检机器人通过电磁悬浮与驱动技术对直流高压输电线进行巡检。简化模型如图所示，机器人由相对位置固定的矩形悬浮线圈 $abcd$ 和驱动线圈 $a'b'c'd'$ 组成，两线圈与高压长直导线 A 处在同一竖直平面内，且 $ab$ 边、$d'a'$ 边均平行于导线 A。机器人始终处在导线 A 产生的磁场区域内，该区域磁场可视为匀强磁场，磁感应强度大小为 $B_{0}$，方向垂直于纸面向里，$ab$ 和 $a'b'$ 边被铁芯包裹，在铁芯作用下，两条边所在处的磁感应强度均增大为原来的 $k$ 倍。当悬浮线圈通有电流恰好使机器人悬浮时，给驱动线圈通另一电流，机器人沿平行于导线 A 的方向以速度 $v_{0}$ 向右匀速运动。已知机器人质量为 $m$，$ab$ 和 $a'b'$ 边的长度均为 $L$，重力加速度为 $g$，机器人运动过程中所受空气阻力保持不变，忽略两线圈之间的相互作用。
\begin{enumerate}
	\item
	求机器人悬浮时悬浮线圈中电流 $I$ 的大小；
	\item
	若给驱动线圈断电，求机器人的速度为 $v_{1}$ 时，$c'd'$ 边产生的感应电动势大小 $E$；
	\item
	若驱动线圈中电流大小保持不变，仅改变方向，机器人移动了距离 $s$ 后停止运动，求此过程中 $a'b'$ 边所受安培力做功的功率 $P$。
\end{enumerate}
\onepicture[align=right, w=8.60cm]{\includesvg{figs/15}}
%% answer:
\jdanswer{
\begin{enumerate}
	\item
	$I = \frac{mg}{(k - 1)BL}$，电流方向为逆时针

	\item
	$E = BLv_{1}$

	\item
	$P = \frac{kmv_{0}^{3}}{8s(k - 1)}$

\end{enumerate}
}
%% memo:
\memoanswer{
（1）根据题意可知，为了使线框整体悬浮，竖直方向上有
\[
kBIL - BIL = mg,
\]
解得
\[
I = \frac{mg}{(k - 1)BL}.
\]
由左手定则可知，电流方向为逆时针。

（2）若机器人向右运行速度为 $v_{1}$，$c'd'$ 边的感应电动势
\[
E = BLv_{1}.
\]

（3）根据题意，若某时刻线框的水平速度为 $v_{0}$，由于 $cd$ 边所受安培力一直为 $ab$ 边所受安培力的 $k$ 倍，设 $cd$ 边所受安培力大小为 $F$，则 $ab$ 边所受安培力大小为 $\frac{F}{k}$，则有
\[
F - \frac{F}{k} = f.
\]
保持电流大小不变，方向反向，则安培力方向反向，由牛顿第二定律有
\[
f + F - \frac{F}{k} = ma.
\]
又有
\[
v_{0}^{2} = 2as.
\]
解得线框 $cd$ 边所受安培力大小为
\[
F = \frac{kmv_{0}^{2}}{4s(k - 1)}.
\]
线框 $cd$ 边所受安培力的平均功率
\[
P = F\bar{v} = F\cdot\frac{v_{0}}{2} = \frac{kmv_{0}^{3}}{8s(k - 1)}.
\]
}

如图所示，光滑水平面上质量为 $m$ 的小球 A 通过两根相同的轻质弹簧分别与质量均为 $\frac{3}{5}m$ 的小球 A$_{1}$、A$_{2}$ 连接，A$_{1}$、A$_{2}$ 分别套在两根平行的细杆上，细杆固定、光滑且足够长。初始时 A、A$_{1}$、A$_{2}$ 位于垂直于细杆的直线上且处于静止状态，每根弹簧都处于原长。现有质量为 $M$ 的小球 B 以速度 $v_{0}$ 沿平行于细杆的方向与 A 发生弹性正碰。
\begin{enumerate}
	\item
	求 A 获得的速度大小 $v_{1}$；
	\item
	在弹簧再次恢复原长的过程中，若 B 与 A 不发生碰撞，求此过程中每根弹簧的最大弹性势能 $E_{p\max}$；
	\item
	在弹簧再次恢复原长时，若 B 又恰能与 A 碰撞，求 A、B 两球的质量之比 $\frac{m}{M}$。
\end{enumerate}
\onepicture[align=right, w=5.40cm]{\includesvg{figs/16}}
%% answer:
\jdanswer{
\begin{enumerate}
	\item
	$v_{1} = \frac{2M}{M + m}v_{0}$

	\item
	$E_{p\max} = \frac{6mM^{2}v_{0}^{2}}{11(M + m)^{2}}$

	\item
	$\frac{m}{M} = \frac{1}{11}$

\end{enumerate}
}
%% memo:
\memoanswer{
（1）小球 B 与小球 A 发生弹性正碰，由动量守恒定律有
\[
Mv_{0} = Mv_{2} + mv_{1},
\]
由能量守恒定律有
\[
\frac{1}{2}Mv_{0}^{2} = \frac{1}{2}Mv_{2}^{2} + \frac{1}{2}mv_{1}^{2},
\]
联立解得
\[
v_{1} = \frac{2M}{M + m}v_{0},\qquad v_{2} = \frac{M - m}{M + m}v_{0}.
\]

（2）小球 A$_{1}$、A$_{2}$、A 共速时，弹簧的形变量最大，弹簧弹性势能最大。由动量守恒定律有
\[
mv_{1} = \left(m + \frac{3}{5}m + \frac{3}{5}m\right)v_{\text{共}},
\]
由能量守恒定律有
\[
\frac{1}{2}mv_{1}^{2} = \frac{1}{2}\left(m + \frac{3}{5}m + \frac{3}{5}m\right)v_{\text{共}}^{2} + 2E_{p\max},
\]
解得
\[
E_{p\max} = \frac{3}{22}mv_{1}^{2} = \frac{6mM^{2}v_{0}^{2}}{11(M + m)^{2}}.
\]

（3）设小球 B 与小球 A 发生弹性正碰后到弹簧再次恢复原长的时间为 $t$，由动量守恒定律有
\[
mv_{1} = mv_{1}' + \left(\frac{3}{5}m + \frac{3}{5}m\right)v',
\]
两边同时乘以 $t$ 并求和可得
\[
mv_{1}t = mx + \left(\frac{3}{5}m + \frac{3}{5}m\right)x.
\]
要使弹簧恢复原长时，B 与 A 能再次发生碰撞，则有
\[
x = v_{2}t.
\]
整理可得
\[
\frac{2M}{M + m}v_{0}t = \frac{11}{5}\cdot\frac{M - m}{M + m}v_{0}t,
\]
解得 $M = 11m$，即 A、B 两球的质量之比
\[
\frac{m}{M} = \frac{1}{11}.
\]
}

\end{enumerate}
