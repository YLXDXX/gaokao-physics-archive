# 异常记录 · 2001 年

> 本文件记录 2001 年各卷的异常与人工核验事项；状态取值与更新方式见 [`../异常记录.md`](../异常记录.md)。
> 排序：待补充 → 待处理/处理中 → 待人工核验 → 已解决；未闭合项在前、已解决项在后，便于人工补充与审核。

## 制作说明

2001 年共 **8 套**、**100 题**：独立物理卷 4 套（上海 23、全国旧课程 22、北京春季理综 22、粤豫 3），理综／综合节选 4 套（全国理综新课程 1、全国理综旧课程 12、上海理综 10、广东综合 7）。其中粤豫无 Docx/PDF，仅依平台 JSON 制作。全部完成学生版 + 教师版编译与 `make check`，图片一律用 JSON 原图或原 PDF 内嵌图无损提取／裁剪，未用 TikZ 重绘。

通用处置：理综／综合节选加卷级标记 `%% paperType: 理综物理部分`（全国理综旧课程、全国理综新课程）、`%% paperType: 综合能力测试物理部分`（上海理综、广东综合），独立物理卷（上海、全国旧课程、北京春季理综、粤豫）不加。节选卷题号不连续，显示序号由 `enumerate` 自动连续编号，元数据 `%% number` 保留平台原题号以便溯源（全国理综旧课程 16–24、29–31；上海理综 13–17、26、27、33、39、46；广东综合 19、20、28–30、33、38；粤豫 1、6、10）。原卷／材料无工作解答者，写 `\memoanswer{本题原卷及材料中未提供详解，待补充。}`。JSON 图失效或缺失者，从原 PDF 无损提取／渲染裁剪回填；可无损拆分的复合图已拆分，图内编号抹除后由宏自动生成，严禁 TikZ 重绘，本年份未引入任何 TikZ 重绘。
