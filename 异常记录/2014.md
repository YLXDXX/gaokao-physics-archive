# 异常记录 · 2014 年

> 本文件记录 2014 年各卷的异常与人工核验事项；**状态取值与更新方式**见
> [`../异常记录.md`](../异常记录.md)。新建年份时复制本模板为 `异常记录/<年份>.md`。

2014 年共 **15 套**（上海、全国理综大纲、全国课标Ⅰ/Ⅱ、北京理综、四川理综、天津理综、
安徽理综、山东理综、广东理综、江苏、浙江理综、海南、福建理综、重庆理综），共 **215 题**，
均已完成制卷（学生版 + 教师版、`make check` 0 错误）。各卷题干、答案、详解以
`材料处理/2014/<地区>/merged.md` 与平台 JSON 为准；图片以 JSON / 原 PDF 内嵌图优先，
复合图逐张拆分核对（未用 TikZ 重绘）。山东、广东、江苏三卷原卷及材料无【解析】，
相应题写占位详解并登记（共 25 题，待补充）。以下为逐题异常。
