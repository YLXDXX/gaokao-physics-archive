# 异常记录 · 2012 年

> 本文件记录 2012 年各卷的异常与人工核验事项；**状态取值与更新方式**见
> [`../异常记录.md`](../异常记录.md)。新建年份时复制本模板为 `异常记录/<年份>.md`。

2012 年共 **14 套**（上海、江苏、海南、全国新课标、全国理综、北京理综、四川理综、天津理综、
安徽理综、山东理综、广东理综、浙江理综、福建理综、重庆理综），均已完成制卷
（学生版 + 教师版、`make check` 0 错误），并经一轮独立逐题复核。各卷题干、答案、详解取自
`材料处理/2012/<地区>/merged.md`；图片以 JSON 矢量图优先，复合图/图选项用
`split_svg.py`（矢量）或原 PDF 渲染裁剪后回填。以下为逐题异常。
