## 一、通用处置

- **理综节选加卷级标记**：`%% paperType: 理综物理部分`；独立卷（上海、江苏、广东）不加。
- **同号题合并**：平台把一道大题拆成多条（实验Ⅰ/Ⅱ、A/B 分叉、选考 (1)(2) 等），制卷时
  合并为单个 `\item`，元数据照抄 JSON 中该题号的**最后一条**（`check_meta` 以此比对），
  正文变体分段并列，答案用一一对应的 `\jdanswer`。
- **题型误标**：JSON 标 `typeId=1/单选题` 而实为计算/填空题者，保留 JSON 元数据、按实际
  题型排版，`%% answer` 填 JSON 提供的字母串以过 `check_meta`，并在此登记（江苏理综第 35 题）。
- **缺详解**：原卷/材料无工作解答者，写 `\memoanswer{本题原卷及材料中未提供详解，待补充。}`，
  合计 **26 题**（上海 1、广东 1、重庆理综 1、上海理综 11、江苏理综 12）。
- **复合图**：可无损拆分的已用 `tools/recrop_figures.py` 拆分回填（裁一张核一张）；
  无法无损拆分或图内标签被正文引用者（上海 17/22、上海理综 34）按原图整体呈现。
- 严禁 TikZ 重绘；本年份未引入任何 TikZ 重绘。
